================================================================================
PERSONAL LIFE OS - QUICK START GUIDE
================================================================================

RACHEL - READ THIS FIRST! Here's all you need to know to get started.

================================================================================
STEP 1: INSTALL
================================================================================

Open your terminal/command prompt and navigate to the personal-life-os folder.

Then run:
  pip install -r requirements.txt

That's it! This downloads the tools the app needs to run.

(If you see an error, make sure you have Python 3 installed. Go to python.org if not.)

================================================================================
STEP 2: RUN THE APP
================================================================================

In the same terminal, run:
  python app.py

You'll see something like:
  ============================================================
  Personal Life OS is starting up!
  ============================================================
  Open your browser to: http://localhost:5000
  ============================================================

That means it's working!

================================================================================
STEP 3: OPEN IN BROWSER
================================================================================

Open your web browser (Chrome, Firefox, Safari, Edge - any will work).

Go to:
  http://localhost:5000

You'll see the mind dump form. You're ready to use it!

================================================================================
HOW TO USE
================================================================================

1. WRITE
   - Click the big text area that says "What's on your mind?"
   - Write whatever is in your head - no filter needed
   - Stream of consciousness is perfect

2. TRACK
   - Mood: Use the slider to rate how you're feeling (1=awful, 10=amazing)
   - Energy: Use the slider to rate your energy level
   - Location: Where you are (optional)
   - Thoughts, Ideas, Urges: Any other details you want to capture (optional)

3. SAVE
   - Click "Save Mind Dump"
   - Your writing is analyzed automatically
   - A daily report appears with insights about your thinking

4. REVIEW
   - Click "View Today's Report" to see patterns in your thoughts
   - Click "View History" to see all your past dumps
   - Watch how patterns emerge over time

================================================================================
WHAT THE APP ANALYZES
================================================================================

After you save a dump, the app automatically:

✓ Extracts keywords - shows you what you're thinking about
✓ Analyzes mood - detects if your tone is positive, negative, or neutral
✓ Finds patterns - looks for anxiety, stress, perfectionism, self-doubt, etc.
✓ Creates recommendations - gives you personalized suggestions based on your state

Example: If you mention "should", "must", "perfect", and "failure" a lot,
the app recognizes perfectionism patterns and suggests focusing on progress
over perfection.

================================================================================
WHERE IS MY DATA?
================================================================================

All your data stays on YOUR computer.

✓ No cloud, no servers, no syncing
✓ Everything is stored in a file called "mind_dumps.db"
✓ You can see it in the same folder as app.py
✓ It's completely private and completely yours

================================================================================
TO STOP THE APP
================================================================================

In your terminal, press:
  CTRL + C  (on Mac: COMMAND + C)

The app stops but your data stays saved.

================================================================================
QUICK TROUBLESHOOTING
================================================================================

Q: I got an error about "port already in use"
A: Something else is using port 5000. Either close that app or edit app.py
   Change the last line from "port=5000" to "port=5001"

Q: The app won't start
A: Make sure you:
   1. Installed dependencies (pip install -r requirements.txt)
   2. Are running from the personal-life-os folder
   3. Have Python 3 installed

Q: I want to start fresh
A: Delete the file "mind_dumps.db" and restart the app.
   It will create a fresh database.

Q: Nothing works, I'm stuck
A: That's okay! Check the README.md file for more detailed help.
